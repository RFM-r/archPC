# Практическая работа №11. Составление технического задания на ввод в эксплуатацию новой компьютерной системы
#### Цель: научиться практически выполнять и составлять техническое задания по внедрению в эксплуатацию новой компьютерной системы.
## Теоретические сведения:
### Представьте, что в компании, которая является ведущей на рынке по работе в определенной области, в главный отдел, состоящий из одинакового парка персональных компьютеров, стала необходимость внедрить новую компьютерную систему и как следствие сменить старый парк ПК на новый. Вы как главный приглашенный Айти специалист были выбраны директором фирмы в качестве ответственного по выполнению данной задачи. Ваша задача составить техническое задание – основной документ по которому будет происходить внедрение новой компьютерной системы.
### 1. Задание:
```shell
    1. Согласно варианту выберете компанию в которой планируется внедрение новой компьютерной системы и по примеру оформления технического задания составьте ТЗ для внедрения новой КС.
    2. Для исследования парка компьютеров используйте свой рабочий компьютер в качестве примера старой существующей компьютерной системы на предприятии.
    3. В качестве примера составления технического задания используйте файл ТЗ_пример оформления.
    4. В техническом задании должны обязательно присутствовать таблицы 1, 2, 3 и 4 из документа Таблицы для ТЗ.
```

### 2. Задание на практическую работу №11:
```shell
    1. Оформите по примеру титульный лист технического задания. (Исходные данные для титульного листа в Приложении 1)
    2. Составьте содержание. Укажите основные разделы и подразделы согласно ГОСТ, которые можно включить в ваше ТЗ. (рекомендуется проработать содержание, но окончательный вариант оформить после написания всего ТЗ) Пример содержания указан в приложении 2
    3. Оформите первый раздел технического задания «Общие сведения» (исходные данные в приложении 3)
        3.1. В пункте 1.1. Укажите полное наименование Своей системы и ее условное обозначение.
        3.2. В пункте 1.2. и 1.3 пропишите номер договора (файл Номер договора) и реквизиты сторон соглашения. Если фирма будет самостоятельно внедрять КС то прописать реквизиты только одной фирмы.
        3.3. Пункт 1.4. не указываем.
        3.4. В пункте 1.5. прописываем сроки работ. Берем средний показатель продолжительности каждого этапа внедрения и прописываем срок.
        3.5. В Пункте 1.6. Прописать источник финансирования (сама фирма, стороння организация, государство)
        3.6. В пункте 1.7. Указать порядок оформления и предъявления работ
    4. Оформите второй раздел технического задания «Назначения и цели создания системы»
        4.1. Во втором разделе оставляем только пункт 2.1. и прописываем в нем Цели и назначение системы (придумать, описать, согласно названию Вашей системы).
    5. Оформите Третий раздел технического задания, добавив и заполнив в него таблицы из файла «Таблицы для ТЗ»
        5.1. В разделе 3. Оставляем пункт 3.2. и прописываем условия эксплуатации системы (Место установки, температура помещения, влажность, запыленность помещения и т.д.). Так же в этот пункт добавляем 2 таблицы с характеристиками системы которая существует.
    6. В четвертом разделе укажите требования предъявляемые  к компьютерной системе.
        6.1. Оставляем пункт 4.1. и прописываем требования к системе (что необходимо предъявить). Можно опираться на пример из ТЗ.
        6.2. Пункт 4.2. Делаем из вторых двух таблиц и прописываем характеристики той системы которую будут устанавливать. 
    7.  Оформите пятый раздел ТЗ
```
### З. Оформление текста должно производится согласно ГОСТ. Шрифт Times New Roman 14(12)пт, 1,5 интервал. Выравнивание по ширине. С соблюдением абзацев.
